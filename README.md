# AliceKit

Ранее Station Studio. Имена пакетов, файлов выпусков и адрес репозитория сохранены для совместимости обновлений.

Локальная панель для Яндекс Станции Макс. Управление и оформление работают на самой колонке. Ноутбук и телефон с AliceBridge для обычной работы не нужны.

## Совместимость

Агент станции проверяет точный профиль: `yandexstation_2`, Android 9 / API 28, сборка `5000000921`, ARM64, уже работающий root и Permissive. Другие модели и сборки пока не поддерживаются установщиком. Приложение управления: Android 6+; один универсальный APK без привязки к процессору телефона. Версия для TV входит в комплект установки.

[Пошаговая инструкция с подсказками и решением частых ошибок](INSTALL-RU.md)

## Установка с телефона (AliceKit 2.8)

Мастер на телефоне ищет как обычные станции через mDNS Яндекса, так и уже установленные панели AliceKit. Отсутствие ответа не доказывает отсутствие root: гостевая сеть и точка доступа могут блокировать обнаружение. Адрес можно указать вручную.

1. Установите `Station-Studio-2.8.0.apk` на телефон. Разрешение на установку обновлений Android запрашивается при необходимости.
2. Подключите телефон и станцию к одной обычной домашней сети Wi-Fi.
3. Если панель на станции уже работает, выберите её в поиске. На ТВ откройте «Настройки → Подключить телефон» и введите одноразовый код.
4. Если панели ещё нет: «Настройка с телефона · ADB и root» → адрес и порт доступного ADB → «Проверить ADB». Для Hybrid Root часто используется порт 5556, но у вашей установки он может отличаться.
5. ADB может запросить разрешение для нового телефона. Подтвердите его на станции. Авторизация AliceBridge и авторизация нового ADB-клиента — разные ключи; доступ к одному приложению не означает доступ к другому.
6. Приложение проверяет `yandexstation_2 / 5000000921 / API 28`, root (UID 0 либо защищённую очередь rootd профиля 0921), Permissive и совместимость файлов. Неизвестные профили не изменяются.
7. После отдельного подтверждения загружается комплект из подписанного общего канала, проверяются SHA-256 архива и всех файлов. YAM загружается из оригинального выпуска автора с закреплённым SHA-256. Установка создаёт резервные копии заменяемых файлов, затем перезапускает станцию.
8. После запуска подключитесь по коду. Для обычного управления ADB, AliceBridge и компьютер не требуются.

Флаг закрепления Hybrid Root применяется только к уже установленной проверенной версии 1.2.4. Начального получения root приложение не выполняет. Для установки нужно оставить не менее 260 МБ в /data после передачи комплекта и 25 МБ в /odm. При обрыве после команды установки она не отправляется автоматически повторно: сначала проверьте состояние станции. Для существующей панели в этом же мастере доступно обновление полного комплекта.

Проверено на настоящей станции: прямой ADB, авторизованный RSA-клиент, root-команды, передача файла и совпадение SHA-256. Полный первичный цикл с нового физического телефона пока не проверен. На своём устройстве сначала выполните проверку без установки.

## Дом с Алисой

В панели: «Мой дом → Подключить → Получить ссылку для входа». Откройте одноразовую ссылку или отсканируйте QR-код на телефоне с вашим аккаунтом Яндекса, подтвердите вход и вернитесь в панель. Регистрация OAuth-приложения, Client ID и внешний сервер авторизации не нужны. Ссылка одноразовая и может истечь на стороне Яндекса. Если Яндекс просит обновить QR, нажмите «Обновить ссылку и QR-код». Панель ожидает подтверждение пять минут и ещё пять минут позволяет завершить уже подтверждённый вход. Проверка идёт при открытом окне подключения. Её можно отменить и получить новую.

Это неофициальный веб-вход по протоколу сообщества [AlexxIT/YandexStation](https://github.com/AlexxIT/YandexStation). Панель создаёт собственную сессию после явного подтверждения; она не читает данные входа установленных приложений и не использует чужие client_id/client_secret. Сессия хранится в закрытом файле на станции, не передаётся HTML-плагинам или серверу проекта. Её права шире iot:view/iot:control: это полноценный веб-вход аккаунта. Яндекс видит факт входа. Не пересылайте ссылку. При истечении сессии потребуется подтвердить вход заново; автоматическое восстановление через широкий x-token намеренно не применяется.

«Отключить аккаунт» удаляет локальную сессию и разрешения плагинов. Для отзыва самой сессии также завершите соответствующий вход в «Яндекс ID → Безопасность → Устройства». Если старое приложение телефона не открывает ссылку, скопируйте её и откройте в браузере либо обновите приложение. Веб-протокол может изменяться на стороне Яндекса.

Устройства отображаются по комнатам; доступны только объявленные самим устройством умения. Команды не повторяются автоматически при неоднозначном ответе. Это облачный интерфейс Яндекса, поэтому нужен интернет. В настройках плагина отдельно выдаются просмотр и управление домом; обновление пакета сбрасывает эти разрешения. Root-службы не изолированы разрешениями HTML-моста.

## Установка с компьютера

1. Получите совместимый root и ADB. Для этой сборки используется AliceBridge / Hybrid Root 1.2.4. Если root уже работает, повторять получение root не нужно.
2. Распакуйте комплект `Station-Studio-Max-0921.zip` на компьютер. Нужны Python 3.10+ и официальные Android Platform Tools.
3. Сначала выполните проверку: `python setup.py --serial АДРЕС_СТАНЦИИ:ПОРТ_ADB`. Без дополнительных флагов установщик ничего не меняет.
4. Установите: `python setup.py --serial АДРЕС_СТАНЦИИ:ПОРТ_ADB --install --reboot`. Если ADB отсутствует в PATH, укажите `--adb ПУТЬ_К_ADB`.
5. Флаг `--pin-root` исправляет запуск уже установленного Hybrid Root 1.2.4 на CPU 0. Он проверяет хеши существующей реализации; неизвестная конфигурация не заменяется. Первичное получение root этим флагом не выполняется.
6. После загрузки откройте AliceKit на телевизоре. Раздел «Настройки → Подключить телефон» выдаёт одноразовый код. Установите APK управления на телефон, выберите найденную станцию и введите код.

При первом запуске службы автозапуска должны быть прочитаны Android, поэтому требуется перезагрузка. Приложение 2.5 умеет устанавливать агент с телефона на уже рутированную поддерживаемую станцию; вариант с компьютером приведён ниже как альтернативный.

Откат файлов агента: `python setup.py --serial АДРЕС:ПОРТ --rollback --reboot`. Рисунки, аудио, сценарии, аккаунты и сохранённые подключения остаются на станции. Установщик сохраняет резервные копии только собственных заменяемых файлов.

## Возможности

- Отдельное TV-приложение: крупные элементы, рамка фокуса, стрелки/OK/Назад, настройка слайдеров и общая медиатека.
- Приватность: локальный поиск известных библиотек аналитики, объявленные разрешения, обратимое отключение дополнительных приложений. Это не доказательство отправки данных и не отключение облака Алисы.
- Выбор источника музыкальной визуализации, семь эффектов, реакция/затухание/порог тишины/скорость, предпросмотр настоящей обложки и её палитры.
- Светлая главная с состоянием дисплея и кольца, быстрыми сценами, музыкой и отдельным пультом.
- Постоянный показ названия и исполнителя или выбранная длительность. Режим 0 означает показ до остановки.
- 22 готовые LED-анимации, 43 цветовые палитры флагов и команды для сохранённых работ.
- Цвета обложки на кольце: основные цвета изображения, вращение, волна, дыхание.
- Команды плеера: пауза, продолжение, следующий, предыдущий, перемотка; повтор и случайный порядок доступны, если их поддерживает приложение.
- Часы, свои дизайны с фоном, рисунки, GIF, короткое видео, покадровый редактор, библиотека и экспорт JSON.
- Пиксельный текст на русском и английском: песня, исполнитель, одна или две строки, выравнивание, интервалы и яркость имени.
- Музыкальные и микрофонные визуализации. Кольцо: эффекты, палитры, отдельные 24 светодиода.
- Замена LED-анимаций пробуждения, слушания, размышления и ответа Алисы с сохранением оригиналов.
- Небольшая дополнительная иконка HDMI из фото или GIF. Это наложение над областью штатного значка; размер и отступы настраиваются. Само приложение Яндекса не переподписывается.
- Каталог голосовых команд и сцен; свои фразы и цепочки действий. Загруженные аудиофайлы можно запускать фразой.
- Выбор установленного музыкального сервиса. Для Spotify TV реализован поиск с выбором первого результата. Аккаунт сервиса и доступность трека по его подписке остаются необходимыми.
- WLED и цветные Yeelight с LAN Control: свет в такт музыке или цветам обложки. Другие системы умного дома пока не включены в адаптеры.
- Очистка кэша выбранных приложений и закрытие неиспользуемых фоновых приложений без удаления аккаунтов.
- Загрузка `.yampkg`, просмотр совместимости и установочных действий, управление службами и журналом.

Штатная Алиса и её озвучка сохраняются. Подмена всего голоса помощника не входит в эту версию; загруженные звуки воспроизводятся как действия сценариев.

## Обновления

Общий канал обновляет APK управления; обновление агента станции пока выполняется повторным запуском установщика. Общие выпуски размещаются в [GitHub Releases](https://github.com/golodgolub-bit/Station-Studio/releases). Приложение проверяет общий канал через интернет, не требует для этого подключения к станции и не открывает сайт пользователю. Каталог подписан отдельным ключом RSA, APK проверяется по размеру, SHA-256, имени пакета и подписи установленного приложения. Установка обновления завершается штатным установщиком Android.

Подключение к колонке требуется для локального управления и установки TV-компонента. Обновление приложения не является обновлением Android на колонке. Совместимая более новая полная прошивка Android этим проектом не предоставляется; неподходящие GSI и образы других моделей не устанавливаются.

## Подключение и данные

Телефон и станция должны находиться в одной домашней сети. Соединение приложения со станцией использует HTTPS с привязкой к её сертификату и отдельный отзываемый ключ для каждого клиента. В APK нет домашнего IP, общего ключа, аккаунтов или данных владельца. Старый HTTP-доступ оставлен для локального браузера; наружу в интернет его публиковать не нужно.

Команды и визуализации обрабатываются на станции. Музыкальные сервисы и штатная Алиса продолжают использовать свои облачные службы. Временная диагностика распознанной команды хранится только в памяти до трёх минут; записи звука панель не создаёт.

## Плагины и совместимость

Поддерживается формат YAM `.yampkg`, а не старый `.yap` для Luna. Установочные команды плагина выполняются с root, поэтому перед установкой панель показывает состав и сценарии. Пример собственного пакета — `stationstudio-hello-1.0.0.yampkg`. Официальный бинарник YAM скачивается с исходного GitHub автора и проверяется по закреплённому SHA-256; он не переупакован в этом архиве.

Удаление Яндекс-приложений, Google Play, чужой root, загрузчик и разделы boot/system/vendor этим общественным установщиком не изменяются. Он устанавливает панель поверх работающей совместимой станции и сохраняет Алису.

## Сборка и исходники

Исходники находятся в архиве `Station-Studio-Source.zip`. Для сборки нужны Go 1.26+, JDK 17, Android SDK с платформой 35 и Build Tools. Подпись APK и подпись общего канала выпуска — разные ключи; закрытые ключи в исходники и релиз не входят. Собственная сборка с другим ключом не может заменить подписанный публичный APK без удаления установленного приложения.

## Новое в 2.4: сообщество, AirPlay и компьютер

**Телефон:** установите Station-Studio-2.8.0.apk. Для новой функциональности также обновите агент станции комплектом Max 0921. Обновление APK телефона отдельно не заменяет агент на станции.

**Компьютер Windows 10/11 x64:** скачайте Station-Studio-PC-2.8.0.exe из выпуска и запустите. Откроется отдельное окно через установленный Microsoft Edge; при его отсутствии используется браузер по умолчанию. Нажмите «Найти станцию в сети». Если поиск не сработал из-за VPN/гостевой сети, введите её локальный адрес. На станции откройте код подключения в настройках, затем введите код в приложении ПК. Ключ шифруется Windows DPAPI. Для последующих подключений телефон не нужен. Проверка обновления есть в меню подключения ПК; обновления сверяются с подписанным каналом и SHA-256. EXE пока без сертификата издателя Windows.

**AirPlay:** Возможности → Загрузки → AirPlay. После установки откройте приёмник на станции, затем «Настроить AirPlay» в его карточке. Устройства Apple должны быть в той же сети; гостевая изоляция мешает обнаружению. Можно выбрать имя, PIN, автозапуск, разрешение и частоту кадров. Изменения имени/PIN применяются после перезапуска приёмника через его экран настроек. DRM-видео не поддерживается. Передача с Apple-устройств проверяется отдельно: наличие приёмника не гарантирует совместимость каждого приложения.

**Сообщество:** отдельная вкладка внутри «Возможности». Встроенные функции находятся в «Обзоре», программы Android — в «Загрузках»/«Установлено». Плагин можно скачать из каталога или загрузить локальный .yampkg; загрузка не равна установке. Посмотрите состав, версию и права, затем подтвердите установку. Настройки и службы открываются в карточке установленного плагина. Удаление архива не удаляет установленную копию; удаление пакета останавливает его управляемые службы.

**Создание:** Сообщество → Мастерская → Создать с ИИ. Скопируйте всю инструкцию в свой ИИ; он уточнит идею, название и эмблему. Готовый SDK с примером и сборщиком — Station-Studio-Creator-SDK.zip в выпуске. Для проверки используйте локальную загрузку пакета. HTML-страница автора изолирована, имеет доступ только к своим параметрам и не получает ключ станции; на ТВ всегда используются стандартные элементы для пульта.

**Публикация:** https://station-studio-community.shaaaape.chatgpt.site. Скачивание без входа, публикация и управление своими выпусками — через ChatGPT. Один новый плагин в день UTC, обновления без суточного лимита. Удаление не освобождает суточный слот. Опубликованные пакеты общедоступны. Root-код автора не является песочницей; отзыв доверия блокирует последующий запуск управляемых служб, но не отменяет уже внесённые кодом изменения.

Каталог и файлы раздаются через GitHub Releases. Публикации, обновления и удаления синхронизируются обычно раз в 15 минут; расписание GitHub может задерживаться. Установка и отзыв прав на собственной станции применяются локально сразу.

## Мастер, дисплей и профиль (2.8)

В поиске можно выбрать обнаруженную обычную станцию и открыть пять шагов: сеть, ADB, root, установка, подключение. Для получения ADB мастер открывает AliceBridge и исходные сообщения сообщества. Сбрасывать уже работающую станцию не требуется. Автоматического root для любой модели нет. На компьютере доступен отдельный путь с оригинальным установщиком; сначала выполняйте проверку модели, затем следуйте инструкции архива.

В разделе «Дисплей» есть отдельные кнопки: «Убрать трек», «Штатный дисплей» и «Погасить». Первая убирает постоянное название и его сохранённый автозапуск. Вторая останавливает пользовательские эффекты матрицы и возвращает штатные анимации. Кольцо без визуализации на матрице сохраняется. «Погасить» оставляет возможность штатных уведомлений Алисы.

В настройках выберите тёмную или светлую Станцию Макс. Выбор хранится на станции, синхронизируется между клиентами и меняет фотографию, материал и верхнюю панель живой модели.

Профиль находится в настройках. Имя и цвет сохраняются отдельно для каждого подключённого устройства. Вход через @AliceKitBot необязателен: нажмите «Войти через Telegram», откройте бота и явно подтвердите вход, затем вернитесь кнопкой бота или вставьте его подтверждение в AliceKit. Первое подтверждение создаёт привязку автоматически. Ссылка и подтверждение действуют пять минут, используются один раз и связаны с запросом этого устройства. На TV можно сканировать QR телефоном и вставить подтверждение на том клиенте, где начат вход.

Это локальные профили подключённых устройств, не облачная синхронизация домов и не выдача доступа к станции по одному Telegram-аккаунту. Сопряжение станции отдельно защищено одноразовым кодом и сертификатом. Секреты бота и ключ подписи находятся только на сервере. В APK и агенте есть только публичный ключ проверки. На станции сохраняются Telegram ID, имя и username; телефон, пароль и сессия Telegram не запрашиваются. Отвязка удаляет Telegram-данные из профиля.

Профиль мобильной установки использует параметр оригинального Hybrid Root `IPV6=drop`: блокируется DNS-over-TLS по IPv6 для защиты DNS-правил; весь IPv6 не отключается. В старой конфигурации `none` на сети с IPv6 root может работать, но защита показывает `DEGRADED / ipv6-unprotected`. Это разные состояния: наличие UID 0 не доказывает полноту сетевой защиты.
