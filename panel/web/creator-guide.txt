ЦЕЛЕВАЯ СРЕДА
AliceKit, rooted Yandex Station Max, Android 9 / API 28, aarch64, профиль YAM yandexstation_2. Другие модели и прошивки не подтверждены. Панель имеет отдельные телефонный и ТВ-интерфейсы. Интернет, Google Play, Spotify Premium, новые Android API и пакеты Linux не гарантированы. Android не является обычным GNU/Linux: нет bash, glibc, systemd, Python или ALSA-демона по умолчанию. Shell-скрипт начинается с #!/system/bin/sh. Нативную программу собирай для Android arm64 или как статический Linux ARM64 binary только при отсутствии зависимости от Android framework; объясни этот выбор. Не вмешивайся в микрофоны, прошивку, загрузчик, SELinux, root-bootstrap или аккаунты без явной отдельной цели пользователя. Не собирай аудио и персональные данные скрытно.

ФОРМАТ ПАКЕТА
.yampkg — tar, сжатый Zstandard (не gzip). Первая запись — MANIFEST.yaml. Затем обычные файлы files/bin/... и files/share/...; ссылки, ../, абсолютные пути и специальные файлы запрещены. Имена: namespace/name, только латинские строчные буквы, цифры, '_' и '-'; каждая часть до 64 символов. Манифест имеет строгую схему. Новые произвольные поля в YAML добавлять нельзя.

Минимальный MANIFEST.yaml (хеши подставь настоящие):
name: author/example
version: 1.0.0
license: MIT
description: Краткое фактическое описание
homepage: https://github.com/author/example
target: yandexstation_2
arch: aarch64
permissions: []
files_sha256:
  share/author.example/station-studio.json: SHA256_ЭТОГО_ФАЙЛА

Для пакета author/example все файлы share/ должны иметь компонент с префиксом author., например share/author.example/. Не используй общий share/station-studio.json. Данные любого своего плагина помещай в его пространство имён. Не используй имена чужих пакетов и namespace yam для обхода этого правила.

По необходимости добавь:
services:
  worker:
    exec: [bin/author-example]
    restart: on-failure
    oneshot: false
    env: {}
    after: []

Путь исполняемого файла должен быть в bin/ и в files_sha256. Аргументы идут массивом, а не командной строкой shell. Разрешённые метаданные зависимостей: depends, recommends, enhances, provides, conflicts, replaces (списки имён). postinstall — массив команды; избегай его без необходимости. Плагин не стартует автоматически только от загрузки архива. Службы запускает пользователь; их включение сохраняет автозапуск. Перезапуск ограничен панелью. Обновление требует повторного доверия к root-версии.

ОГРАНИЧЕНИЯ
Локальный архив: до 64 МиБ; публикация в общем каталоге: до 32 МиБ. До 256 МиБ распакованных данных, до 64 МиБ на файл, до 10000 записей. После установки должно оставаться место для Android. Не добавляй в пакет APK с неизвестного зеркала, чужую музыку, ключи, учётные данные или пиратские сервисы. Root-служба имеет полный доступ к системе: permissions в YAM — описание, а не системная песочница. Не обещай отдельную изоляцию сети или микрофона для root-службы.

{

  "title": "Название плагина",

До 24 полей; id соответствует ^[a-z][a-z0-9_]{0,39}$. Панель сохраняет его атомарно, без автоматического рестарта службы. Остальное окружение: YAM_ROOT, YAM_PKG, YAM_ETC, YAM_VAR, YAM_RUN, YAM_PLATFORM, ANDROID_ROOT, ANDROID_DATA, PATH. Файл настроек не содержит ключ панели.

СОБСТВЕННЫЙ ИНТЕРФЕЙС И 3D (ALICEKIT 2.6)
В station-studio.json добавь "ui":"station-ui.html". Для полноэкранной сцены добавь "uiMode":"scene"; для обычной страницы "uiMode":"panel" или не указывай. Если реально реализован пульт, добавь "uiTV":true: иначе на ТВ будут только стандартные fields. Даже для сцены сохраняй основные настройки в fields. Сам station-ui.html — не больше 256 КиБ, находится рядом с JSON. Все HTML, модели, текстуры, шрифты, аудио и локальные JS-библиотеки включи в files_sha256. Ресурсы размещай рядом с HTML, например assets/scene.glb. Один ресурс через мост — до 16 МиБ, общий пакет подчиняется лимитам выше.

HTML работает в iframe sandbox allow-scripts с непрозрачным origin. Нет доступа к DOM родителя, ключу станции, аккаунтам, shell, чужим плагинам и произвольным API. CSP: default-src 'none'; script-src 'unsafe-inline' blob:; style-src 'unsafe-inline'; img-src data: blob:; media-src data: blob:; font-src data: blob:; connect-src blob:; frame-src 'none'; worker-src blob:; base-uri 'none'; form-action 'none'. Внешних CDN и сетевых запросов нет. Не выдавай изоляцию HTML за изоляцию root-службы.

Мост postMessage, канал station-studio-v1. Запрос {channel,id,action,...}. Ответ {channel,id,result} либо {channel,id,error}. Проверяй event.source===parent, канал и свой id. Только один незавершённый запрос; тайм-аут 15 секунд, ошибки показывай пользователю, физические команды не повторяй автоматически. crypto.randomUUID на старом WebView может отсутствовать, используй Date.now()+счётчик.
Доступные действия:
- settings.read: result содержит panel,values и метаданные своего пакета.
- settings.write: передай values со ВСЕМИ полями своей схемы. Сначала подтверждение, потом обновление UI.
- assets.read: передай path:"assets/scene.glb"; result {path,mime,bytes:ArrayBuffer}. Путь относительно каталога своего HTML, только установленный файл с верным SHA-256. Не абсолютный путь/../ и не HTTP URL.
- runtime.info: edition:"tv" или "touch", input:"remote" или "pointer", version, assetLimit, htmlLimit, externalNetwork:false, assets:true. Версия API не доказывает возможности GPU: проверяй контекст отдельно.
- home.read и home.control: только с отдельными разрешениями, описание ниже.

Загрузка локальной библиотеки без eval: const a=await call('assets.read',{path:'assets/library.js'}); const script=document.createElement('script'); script.textContent=new TextDecoder().decode(a.bytes); document.head.append(script). Используй собранную IIFE/UMD-версию; ES-модули со множеством относительных импортов заранее собери в один локальный файл. CSP разрешает inline script, однако не unsafe-eval: библиотека не должна зависеть от eval/new Function. Это исполняется только внутри изолированного iframe, не в родителе. Blob script может не загрузиться в старых Android WebView, поэтому не делай его единственным способом загрузки JS. Для GLB передавай ArrayBuffer парсеру, встроенные текстуры — в GLB; для изображений создавай Blob URL и освобождай после использования. Относительный fetch('assets/...') внутри srcdoc не работает. Сохраняй лицензии и уведомления всех библиотек. SDK содержит полный мост и пример без сторонних зависимостей.

Можно создавать WebGL-пространства, процедурные миры, модели, галереи, игры, редакторы, локальные эффекты и Canvas2D. Для Station Max Android9 начинай с WebGL1/GLSL ES1.00; WebGL2 — только после feature detection, с резервным вариантом. Не требуй WebGPU, desktop OpenGL, WASM threads, SharedArrayBuffer или COOP/COEP. Начальный бюджет: 30 FPS, devicePixelRatio не выше 1.5, текстуры до 1024, до ~50000 треугольников; это рекомендация, не гарантия GPU. Настрой качество. Не рендери при document.hidden; обрабатывай webglcontextlost/restored; освобождай GPU/Blob URL/таймеры при pagehide и удалении iframe. Учитывай prefers-reduced-motion; кадры по вводу или таймеру, если непрерывная анимация не нужна. Потеря GPU не должна превращаться в пустой экран.

ТВ-пульт: родитель шлёт {channel:'alicekit-input-v1',type:'keydown',key:'up'|'down'|'left'|'right'|'enter'|'focus'}. При type:'viewport' приходят width,height. Проверяй источник===parent. Пользователь явно нажимает «Управлять сценой»; Назад сначала выходит из сцены, затем закрывает окно. Реализуй стрелки/OK и понятную подсказку. Сенсор: touch/pointer с прокруткой страницы, без ловушки жестов. Пользователь всегда может закрыть плагин. Не перехватывай системные Back/Home.

УМНЫЙ ДОМ (ALICEKIT 2.5)
Пользователь подключает Дом с Алисой одноразовой ссылкой Яндекса; регистрация OAuth-клиента не нужна. Сессия остаётся на станции, HTML-плагины не получают её. Панель использует неофициальный облачный веб-интерфейс; не обещай офлайн-работу или неизменность протокола. Мост также совместим с отдельно настроенным официальным OAuth.
Дополнительно к settings.read/settings.write мост station-studio-v1 поддерживает:
{channel:"station-studio-v1",id:"unique",action:"home.read"}
Ответ result содержит connected, devices, rooms, groups, scenarios, households, без OAuth-токена.
{channel:"station-studio-v1",id:"unique",action:"home.control",data:{id:"ID_DEVICE",actions:[{type:"devices.capabilities.on_off",state:{instance:"on",value:true}}]}}
Не выдумывай capability: бери type, instance и доступные значения из devices[].capabilities. Проверяй ошибки ответа; не повторяй физическую команду автоматически при тайм-ауте. Отображай offline, пустой дом и отсутствие подключения.
Пользователь выдаёт просмотр и управление отдельно в параметрах установленного плагина. По умолчанию оба выключены. Управление подразумевает просмотр. Разрешение привязано к хешу манифеста всей версии; обновление требует повторного согласия. Отзыв чтения отзывает управление. Root-службы не изолированы этим мостом и по-прежнему требуют отдельного полного доверия. Запрещено искать токен Яндекса на диске или запрашивать его у пользователя для своего HTML.
Функции, которых НЕТ: универсальная замена HDMI-значка Алисы (есть лишь необязательное наложение), автоматический root неизвестных прошивок, гарантированный поиск песни в любом стриминге, обход DRM/подписки. Не обещай это в плагинах.

РАСШИРЕНИЯ BRIDGE ALICEKIT 2.7
Проверяй runtime.info: telemetry/mediaControl/displayPreview — наличие API, а не выданное разрешение. Все три разрешения выключены по умолчанию. Пользователь выдаёт их своей версии плагина в его параметрах; смена версии или файлов отзывает их. Обрабатывай 403 понятной подсказкой, не зацикливай запросы. Root-службы по-прежнему имеют полный системный доступ и не ограничены этой песочницей.
- station.read: отдельное разрешение telemetry. Ответ {timestamp,width:25,height:16,frame:base64,ring:[[R,G,B] x24],displayAvailable,ringAvailable,brightness,assistant}. Это аппаратные данные, не рисунок конфигурации. Если доступность false — показывай недоступность, не придумывай состояние. Опрашивай не чаще 4 раз/с, только пока сцена видна. Не получает микрофон, распознанную речь, токены или root.
- media.control: отдельное разрешение media, передай command: play|pause|next|previous. Управляет выбранным пользователем музыкальным сервисом. Это не произвольный Intent, поиск, URL или shell. Проверяй ответ, плеер может не поддерживать команду.
- display.preview: отдельное разрешение display. Передай frames:[base64...],delays:[мс...],duration:1..8 секунд,brightness:1..100. От 1 до 80 кадров, каждый ровно 400 байт монохромной яркости, порядок y*25+x. Задержка 66..2000 мс. Это временный предпросмотр; не отключает часы, не переписывает реакции Алисы и не включает бесконечный фон. Если Алиса занята/идёт другой предпросмотр — 409, предложи повторить вручную. Не повторяй автоматически. Версия станции без подтверждённого LED может отклонить показ.
3D сцена может читать station.read и воспроизводить настоящий свет кольца на собственной геометрии, а display.preview использовать для ручного короткого предпросмотра авторской анимации. Освобождай WebGL текстуры, геометрию, таймеры и AudioContext при pagehide. Сообщение alicekit-input-v1 type:viewport сообщает размер; пересчитывай камеру без постоянного выделения GPU ресурсов.

Только разрешённые HTTPS CDN изображения доступны в основной панели; HTML песочница не получает произвольный сетевой доступ, а assets.read предназначен для собственных упакованных ресурсов.
