# Настройки расширений в AliceKit

Откройте **Возможности → Загрузки → Загрузить пакет**. Выберите `.yampkg`,
проверьте автора, совместимость, команды и права. Загрузка не запускает код.
Установка требует отдельного подтверждения. Плагин появляется в разделе
**Установлено**; здесь доступны его службы, автозапуск, журнал и настройки.

Пакеты YAM исполняются с root. Панель не гарантирует безопасность кода автора.
Старые пакеты `.yap` не превращаются автоматически в совместимые `.yampkg`.

## Для автора плагина

Включите `files/share/author.plugin/station-studio.json` в архив YAM и добавьте его SHA-256
в `files_sha256` обычного `MANIFEST.yaml`. Поля самого манифеста менять не нужно.
Описание интерфейса проверяется по хешу установленного пакета. Исполняемые команды в JSON запрещены. Для отдельного HTML-интерфейса укажите `"ui":"station-ui.html"` и добавьте этот файл рядом с JSON, также с SHA-256. Он открывается в изолированном окне, без сети и ключа станции. На ТВ стандартные поля доступны всегда. С 2.6 авторский UI с `uiTV:true` также открывается на ТВ и должен реализовать стрелки/OK.

Для пакета `author/plugin` используйте каталог `share/author.plugin/`. Это обязательное правило YAM: общий путь без пространства имён будет отклонён.

Пример `share/author.plugin/station-studio.json`:

```json
{
  "version": 1,
  "title": "Оформление",
  "fields": [
    {"id":"enabled", "label":"Включено", "type":"toggle", "default":true},
    {"id":"brightness", "label":"Яркость", "type":"range",
     "default":40, "min":5, "max":100, "step":5},
    {"id":"palette", "label":"Гамма", "type":"select",
     "default":"Океан", "options":["Океан","Закат"]},
    {"id":"caption", "label":"Подпись", "type":"text", "default":"",
     "hint":"Текст, который использует ваше расширение"}
  ]
}
```

Поддерживаются до 24 полей: `toggle`, `range`, `select`, `text`. Идентификатор:
строчная латинская буква, далее буквы, цифры и `_`, до 40 знаков. Каждое поле
обязательно имеет корректное значение `default`. Для диапазона нужны `min`,
`max` и положительный `step`; для списка — `options` (до 24 строк). Текстовые
значения ограничены 512 байтами UTF-8. Заголовок и подпись поля — до 120 байт.

При старте управляемой службы панель передаёт переменную окружения
`STATION_STUDIO_SETTINGS` с абсолютным путём к JSON-файлу значений:

```json
{"enabled":true,"brightness":40,"palette":"Океан","caption":""}
```

Служба должна сама читать этот файл. Панель сохраняет настройки атомарно,
не подставляет их в команды shell и не перезапускает службу без действия
пользователя. Можно перечитывать файл при изменении либо попросить пользователя
нажать **Перезапустить**. Настройки сохраняются при обновлении пакета;
несовместимые с новой схемой значения заменяются значениями по умолчанию.

Эти же поля автоматически отображаются в телефонной и телевизионной версиях.
На ТВ диапазон редактируется так: OK, стрелки влево/вправо, OK для завершения.
Необъявленные пакетом настройки панель не угадывает: у старых расширений
доступны управление службами и журнал.


## Дом с Алисой (2.5)

Пользователь подключает аккаунт через Яндекс ID в приложении телефона. HTML-интерфейсу ключи не передаются. В его настройках отдельно выдаются просмотр и управление домом, привязанные к хешу манифеста версии. Отключение аккаунта, смена аккаунта и удаление плагина отзывают эти разрешения. Root-службы не ограничены HTML-мостом.

Мост `station-studio-v1`: `home.read` возвращает `connected`, `devices`, `rooms`, `groups`, `scenarios`, `households`. Команда `home.control` получает `data: {id, actions: [{type, state: {instance, value}}]}`. Используйте только объявленные устройством умения из `devices[].capabilities`. Управление подразумевает просмотр. Без разрешения ответ содержит ошибку. Не повторяйте команды при неопределённом результате: физическое действие могло выполниться.

Пример: `parent.postMessage({channel:'station-studio-v1', id:'read-home', action:'home.read'}, '*')`. Ответ нужно сверять по `channel` и `id`, обрабатывать `error` и `result`. При `connected:false` предложите подключить аккаунт в основном приложении. Для переключателя лампы: `action:'home.control', data:{id:'ID_ИЗ_СПИСКА',actions:[{type:'devices.capabilities.on_off',state:{instance:'on',value:true}}]}`. Не используйте выдуманный ID или capability.

Полная актуальная инструкция для любого ИИ включена в `CREATOR-AI-RU.txt` SDK и копируется в разделе «Сообщество → Создать с ИИ». Для ТВ нужны стандартные fields, работающие с пульта. Оформление HTML получает базовые CSS-переменные приложения; их технические имена перечислены в инструкции.


## 3D-пространства и локальные ресурсы (2.6)

Укажите `"uiMode":"scene","uiTV":true` рядом с `"ui":"station-ui.html"`. Полноэкранная сцена сохраняет штатный выход Назад и стандартные fields. Собственные GLB, текстуры, шрифты, аудио и JS-библиотеки включаются в files_sha256. `assets.read` с `path:"assets/scene.glb"` возвращает `{path,mime,bytes:ArrayBuffer}`; создайте Blob URL или передайте буфер парсеру. Лимит16МиБ на ресурс,256КиБ на HTML; общие лимиты пакета сохраняются. Нельзя использовать внешний CDN. Ресурс проверяется по хешу и пространству имён установленной версии.

`runtime.info` сообщает edition,input,limits,externalNetwork:false. Это не гарантия WebGL2. Базовая цель Android9 — WebGL1/GLSL ES1.00; предусмотрите fallback, context loss, паузу фонового рендера и reduced motion. Телевизионный вход после явного «Управлять сценой»: сообщения от parent, channel `alicekit-input-v1`, type `keydown`, key up/down/left/right/enter/focus; отдельно type viewport с width,height. Проверяйте event.source. Back сначала освобождает управление сценой.

Готовый пример `example-3d` в Creator SDK не содержит root-служб или скрытой сети. Подробный универсальный промпт, рекомендации моделей и все ограничения находятся в CREATOR-AI-RU.txt. Промпт объясняет среду модифицированной станции, поэтому предварительные знания модели о её взломе не нужны.


## Разрешения станции (2.7)

station.read возвращает аппаратный кадр LED, RGB кольца, яркость и состояние занятости Алисы. media.control управляет только выбранным плеером: play/pause/next/previous. display.preview показывает 1–80 кадров по 400 байт, задержки 66–2000 мс, яркость 1–100, длительность 1–8 секунд. Все три возможности имеют отдельные разрешения в параметрах установленной версии. При смене версии или содержимого они отзываются; при удалении пакета разрешения удаляются. Это не root. Предпросмотр уступает Алисе и возвращает прежние часы/музыкальный фон. Ошибку 409 нельзя автоматически повторять.

Пример: await call('station.read'); await call('media.control',{command:'pause'}); await call('display.preview',{frames:[btoa(String.fromCharCode(...new Uint8Array(400)))],delays:[100],duration:2,brightness:60}). Обрабатывайте 403 и объясняйте, какое разрешение нужно включить. Состояние опрашивается не чаще 4 раз/с и только пока сцена видна. Ключи, распознанная речь и микрофон интерфейсу не выдаются. Полный контракт включён в универсальный промпт.
