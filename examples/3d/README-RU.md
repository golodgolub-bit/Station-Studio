# Orbit — пример 3D-плагина AliceKit 2.6

Рабочая WebGL1-сцена, локальная библиотека и JSON-палитра через assets.read. Не содержит служб, не управляет LED, домом или микрофонами. Без root-разрешения на выполнение. UI поддерживает сенсор, стрелки/OK и штатный выход Назад.

Сборка: pluginpack.exe example-3d orbit-1.0.4.yampkg
Установка: Возможности → Сообщество → Загрузить свой пакет. Затем Установлено → Orbit → Открыть 3D-пространство.
Параметры хранятся в стандартных fields. Кнопка Пауза меняет состояние только открытой сцены. Для постоянных изменений используйте стандартные настройки.

Без WebGL выводится объяснение вместо пустого экрана. Качество зависит от WebView/GPU устройства. Исходники MIT, внешних библиотек нет.
