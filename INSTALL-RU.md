# AliceKit: установка и первые настройки

Панель работает на самой станции. Телефон служит пультом; постоянно включённый компьютер для повседневной работы не нужен.

## С телефона: короткий путь

1. Установите AliceKit APK из [последнего выпуска](https://github.com/golodgolub-bit/Station-Studio/releases/latest). Другие файлы выпуска для обычного подключения скачивать не нужно.
2. Подключите телефон и станцию к одной Wi-Fi сети. Нажмите «Найти станцию» и выберите свою. Готовая панель открывается по сохранённому подключению или коду с ТВ.
3. Если ADB ещё выключен, мастер предложит AliceBridge и шаги именно для вашей модели. Если ADB уже работает, повторять настройку и сбрасывать колонку не нужно. AliceKit сам проверяет порты 5555/5556; ключи двух приложений различаются.
4. Уже полученный root определяется проверкой. Повторное получение пропускается. Для первого root на совместимой Max 0921: откройте оригинальный файл автора в Telegram → «Поделиться» → AliceKit. Распаковывать архив, переносить папки или выбирать 9 файлов не нужно. Проверенный комплект сохраняется в закрытом хранилище приложения. Альтернатива — один раз выбрать скачанный файл внутри мастера. Сам файл автора в выпуск AliceKit не включён.
5. Роутер и локальный DNS мастер пробует прочитать **со станции**. Неопределённые или неоднозначные адреса не угадываются. Под полями есть объяснение, что проверить в рабочей настройке AliceBridge. Адрес DNS в Hybrid Root — назначение DNS-запросов, которые будут направляться на роутер; это не обязательно IP телефона и не IP колонки.
6. После подтверждения установки root мастер предлагает перезагрузку и проверку автозапуска. При обрыве связи нажмите «Проверить результат»: это чтение квитанции и состояния, без новой попытки root. При непонятной ошибке сохраните локальный журнал. Не запускайте второй установщик параллельно.
7. Нажмите «Установить на станцию». Подписанный комплект скачивается и проверяется автоматически. После запуска подключите телефон по коду с ТВ.

Первый root с этого мобильного клиента остаётся экспериментальным: на нерутированной физической станции он пока не проверен. Проверены ограничения, обработка файлов, квитанции и транспорт; рабочий root текущей станции не сбрасывался для эксперимента.

При первом входе AliceKit предлагает настройки технической диагностики. Это отдельное добровольное действие: приложение работает без отправки. Можно увидеть состав отчёта, отправить один отчёт или отдельно разрешить будущие, отозвать разрешение и удалить отправленные данные. Серверный приём пока закрыт до подтверждения условий обработки и хранения; согласие не включает его автоматически.

- На телефон: `Station-Studio-<версия>.apk`, Android 6 или новее.

Сначала проверьте модель. Комплект рассчитан только на **Station Max `yandexstation_2`, Android 9, сборка `5000000921`, ARM64**. Поддержка других сборок не подтверждена. Установщик остановится при несовпадении профиля.

## Установка с телефона (AliceKit 2.8)

Мастер на телефоне ищет как обычные станции через mDNS Яндекса, так и уже установленные панели AliceKit. Отсутствие ответа не доказывает отсутствие root: гостевая сеть и точка доступа могут блокировать обнаружение. Адрес можно указать вручную.

1. Установите `Station-Studio-2.8.2.apk` на телефон. Разрешение на установку обновлений Android запрашивается при необходимости.
2. Подключите телефон и станцию к одной обычной домашней сети Wi-Fi.
3. Если панель на станции уже работает, выберите её в поиске. На ТВ откройте «Настройки → Подключить телефон» и введите одноразовый код.
4. Если панели ещё нет: «Настройка с телефона · ADB и root» → адрес и порт доступного ADB → «Проверить ADB». Для Hybrid Root часто используется порт 5556, но у вашей установки он может отличаться.
5. ADB может запросить разрешение для нового телефона. Подтвердите его на станции. Авторизация AliceBridge и авторизация нового ADB-клиента — разные ключи; доступ к одному приложению не означает доступ к другому.
6. Приложение проверяет `yandexstation_2 / 5000000921 / API 28`, root (UID 0 либо защищённую очередь rootd профиля 0921), Permissive и совместимость файлов. Неизвестные профили не изменяются.
7. После отдельного подтверждения загружается комплект из подписанного общего канала, проверяются SHA-256 архива и всех файлов. YAM загружается из оригинального выпуска автора с закреплённым SHA-256. Установка создаёт резервные копии заменяемых файлов, затем перезапускает станцию.
8. После запуска подключитесь по коду. Для обычного управления ADB, AliceBridge и компьютер не требуются.

Флаг закрепления Hybrid Root применяется только к уже установленной проверенной версии 1.2.4. Первичный root доступен только экспериментальным установщиком оригинального Hybrid Root 1.2.4 в отдельном шаге; на нерутированной станции полный цикл этим клиентом не проверен. Рабочий root повторно получать не нужно. Для установки нужно оставить не менее 260 МБ в /data после передачи комплекта и 25 МБ в /odm. При обрыве после команды установки она не отправляется автоматически повторно: сначала проверьте состояние станции. Для существующей панели в этом же мастере доступно обновление полного комплекта.

Проверено на настоящей станции: прямой ADB, авторизованный RSA-клиент, root-команды, передача файла и совпадение SHA-256. Полный первичный цикл с нового физического телефона пока не проверен. На своём устройстве сначала выполните проверку без установки.

## Если AliceBridge уже получил ADB, а AliceKit не подключается

1. Откройте мастер. Он сам проверяет обычный порт 5555 и защищённый 5556. Адрес берётся из поиска или вводится из AliceBridge. Другой порт задаётся в раскрывающемся разделе.
2. «ADB включён, AliceKit ещё не разрешён» означает именно отказ новому ключу. Это не отсутствие ADB и не повод повторять сброс или root. У каждого приложения свой закрытый ключ.
3. Если на ТВ появилось окно отладки, разрешите подключение. Если окна нет и в AliceBridge уже работает ROOT-терминал **станции**, нажмите «Разрешить ключ AliceKit» и скопируйте подготовленную публичную команду в этот терминал. Ожидаемый результат `ALICEKIT_PUBLIC_KEY_ADDED`; затем повторите проверку. Команда дополняет обычный `/data/misc/adb/adb_keys`, не отключает аутентификацию и не трогает закрытый sidecar 5556. Поддержка стандартного файла ключей зависит от adbd вашей прошивки.
4. `ALICEKIT_NEEDS_ROOT_TERMINAL` означает, что терминал не имеет root. Не запускайте команду на телефоне и не меняйте файлы защищённого ADB вслепую. Сохраните оба журнала: AliceKit и AliceBridge.
5. Если AliceKit уже установлен, подключитесь к панели по коду. Для обычного управления ADB вообще не требуется. Сохранённая пара подтверждается закреплённым сертификатом, даже если IP станции изменился.

Мастер показывает текущий этап, проверенные порты, результат и следующий шаг. Проверку можно остановить; операции записи/root не повторяются автоматически. В «Журнале подключения» доступны просмотр, копирование, сохранение файла и очистка. Локальные адреса могут быть в экспортированном файле.

### Shizuku, Shevery и права телефона

Эти менеджеры запускают службу на **телефоне**. Установка менеджера не доказывает запуск службы, выданное AliceBridge разрешение или наличие root станции. AliceKit намеренно не показывает выдуманный статус чужой службы.

- Для режима AliceBridge без root телефона нужен поддерживаемый им Android 13+ и рабочий менеджер. В Android включите Wi-Fi, параметры разработчика и беспроводную отладку. В Shizuku выполните сопряжение по коду из настроек **телефона**, затем отдельно нажмите запуск службы. Разрешите доступ именно AliceBridge в запросе менеджера. Запустите сетевой режим в AliceBridge и дождитесь его проверки хотспота, DNS и ADB станции.
- Shevery — альтернативный менеджер с отдельным пакетом. Используйте его только при фактической поддержке в вашей версии AliceBridge. На HyperOS проверьте отдельную отладку с настройками безопасности и фоновую работу; форк сам по себе не гарантирует исправления сети. Не удаляйте рабочий менеджер автоматически.
- Root/DFRoot + KernelSU — другой путь для самого телефона. Следуйте проверке совместимости AliceBridge, выдайте ему суперпользователя в менеджере и выполните требуемую автором перезагрузку телефона после DFRoot. Этот root не равен закреплению root станции.
- Уже работающий ADB можно использовать непосредственно из AliceKit без запущенных Shizuku/Shevery и без root телефона. Новое получение доступа не нужно только ради панели.

Ссылки: [AliceBridge](https://github.com/Yandex-Station-Universal-Repo/AliceBridge_APP), [Shizuku](https://shizuku.rikka.app/guide/setup/), [Shevery](https://github.com/HmnDev-Tech/shevery). За основу берётся фактическая версия и её инструкция, не номер из старого сообщения.

## Дом с Алисой

В панели: «Мой дом → Подключить → Получить ссылку для входа». Откройте одноразовую ссылку или отсканируйте QR-код на телефоне с вашим аккаунтом Яндекса, подтвердите вход и вернитесь в панель. Регистрация OAuth-приложения, Client ID и внешний сервер авторизации не нужны. Ссылка одноразовая и может истечь на стороне Яндекса. Если Яндекс просит обновить QR, нажмите «Обновить ссылку и QR-код». Панель ожидает подтверждение пять минут и ещё пять минут позволяет завершить уже подтверждённый вход. Проверка идёт при открытом окне подключения. Её можно отменить и получить новую.

Это неофициальный веб-вход по протоколу сообщества [AlexxIT/YandexStation](https://github.com/AlexxIT/YandexStation). Панель создаёт собственную сессию после явного подтверждения; она не читает данные входа установленных приложений и не использует чужие client_id/client_secret. Сессия хранится в закрытом файле на станции, не передаётся HTML-плагинам или серверу проекта. Её права шире iot:view/iot:control: это полноценный веб-вход аккаунта. Яндекс видит факт входа. Не пересылайте ссылку. При истечении сессии потребуется подтвердить вход заново; автоматическое восстановление через широкий x-token намеренно не применяется.

«Отключить аккаунт» удаляет локальную сессию и разрешения плагинов. Для отзыва самой сессии также завершите соответствующий вход в «Яндекс ID → Безопасность → Устройства». Если старое приложение телефона не открывает ссылку, скопируйте её и откройте в браузере либо обновите приложение. Веб-протокол может изменяться на стороне Яндекса.

Устройства отображаются по комнатам; доступны только объявленные самим устройством умения. Команды не повторяются автоматически при неоднозначном ответе. Это облачный интерфейс Яндекса, поэтому нужен интернет. В настройках плагина отдельно выдаются просмотр и управление домом; обновление пакета сбрасывает эти разрешения. Root-службы не изолированы разрешениями HTML-моста.

## 1. Подготовить станцию для установки с компьютера

Нужны уже работающие ADB и совместимый root / Permissive. Для указанной сборки используется AliceBridge / Hybrid Root 1.2.4. [Сообщение о root](https://t.me/c/4457409211/32149/71703), [сообщение об ADB](https://t.me/c/4457409211/32149/76312), [доступ после перезапуска](https://t.me/c/4457409211/32149/103161). Ссылки доступны участникам чата. Сверяйте модель и сборку перед применением инструкции.

В мастере есть экспериментальный запуск оригинального Hybrid Root 1.2.4 с телефона, без ПК. Он требует уже доступного и авторизованного ADB, точного профиля Max 0921 и оригинального ZIP сообщества. Все девять файлов проверяются по закреплённым SHA-256. Сам архив в AliceKit не включён. Неизвестная сборка, изменённый архив и повторная операция блокируются. Первичное получение root этим новым мобильным клиентом на нерутированной физической станции пока не проверено; обработка архива и протокол установки проверены на изолированном имитаторе. Работающий root повторно получать не нужно. Флаг `--pin-root` помогает закрепить **уже установленную, проверяемую** реализацию Hybrid Root 1.2.4. Неизвестные файлы root он не заменяет.

На компьютере установите Python 3.10+ и [официальные Android Platform Tools](https://developer.android.com/tools/releases/platform-tools). Подключитесь к доступному ADB станции. Авторизуйте только свои устройства.

## 2. Установить агент

Распакуйте комплект. Откройте терминал в этой папке. Вместо `АДРЕС:ПОРТ` укажите адрес и порт **своей** станции.

Сначала проверка, без изменений:

```text
python setup.py --serial АДРЕС:ПОРТ
```

Если профиль и root прошли проверку:

```text
python setup.py --serial АДРЕС:ПОРТ --install --reboot
```

При необходимости добавьте `--adb ПОЛНЫЙ_ПУТЬ_К_ADB`. Для поддерживаемого установленного Hybrid Root можно добавить `--pin-root`. Дождитесь загрузки станции и ответа Алисы. Не отключайте питание во время установки.

Комплект устанавливает панель, TV-приложение и службы оформления. Он не устанавливает Google Play, другую версию Android и новый способ первоначального root. Домашние адреса, аккаунты и ключи автора в комплект не входят.

## 3. Подключить телефон

1. Установите APK управления. Разрешение «Установка неизвестных приложений» понадобится Android только для запуска установщика APK.
2. Подключите телефон и станцию к одной домашней Wi-Fi сети. Гостевая сеть с изоляцией устройств не подходит. VPN может мешать локальному поиску.
3. На телевизоре откройте AliceKit → «Настройки» → «Устройства и установка». Создайте одноразовый код подключения.
4. На телефоне выберите найденную станцию и введите этот код. Если поиск не сработал, введите локальный адрес вручную.

Код нужен при подключении нового устройства. Он не является паролем Яндекса или Spotify. В дальнейшем приложение использует сохранённый отдельный ключ; его можно отозвать в настройках станции. Не открывайте порты панели в интернет.

## 4. Настроить музыку

Установите нужный плеер на станции, откройте его и войдите в свой аккаунт. В панели → «Музыка» выберите установленный сервис. Проверьте воспроизведение кнопкой поиска, затем фразой «Алиса, включи песню …».

Spotify TV проверялся на указанной Station Max. Поддержка поиска, перемотки, повтора и случайного порядка у других плееров зависит от их MediaSession. Подписка и ограничения музыкального сервиса сохраняются. Если плеер сообщает, что действие недоступно, панель не обходит это ограничение.

Короткие команды «играй», «пауза», «следующий», «назад», «хватит», «стоп» передаются выбранному плееру из распознавания станции. Доступность распознавания без слова «Алиса» зависит от прошивки и контекста. Будильники и ответ помощника сохраняют приоритет. Не назначайте одну короткую фразу нескольким собственным сценариям.

## 5. Оформить станцию

«Оформление» разделено по поверхностям:

- **Дисплей**: часы, название песни, рисунки, GIF, короткое видео. Экран Max монохромный, 25×16 точек; цвет преобразуется в яркость. Регуляторы экспозиции и полутонов помогают сохранить тёмные детали. Режим времени `0` — постоянный показ.
- **Кольцо**: цвет, палитра, флаги, эффекты и 24 отдельных светодиода.
- **Алиса**: подготовьте медиа, посмотрите LED-предпросмотр, назначьте его состоянию «Слушает», «Думает» или другому, затем примените. Оригиналы сохраняются. HDMI-значок настраивается отдельно и является наложением на область штатной иконки.
- **Свет и звук**: музыкальная визуализация кольцом, дисплеем и поддерживаемыми лампами. По умолчанию берётся звук выбранного сервиса. «Весь звук, включая видео» включайте только намеренно.

В режиме «Цвета обложки» показываются цвета полученного изображения. Если сервис не передал обложку, панель сообщает об этом и не подставляет случайную палитру. Чувствительность, скорость вспышки, затухание и порог тишины настраиваются отдельно. Для ламп нужны WLED или цветные Yeelight с включённым LAN Control; другие системы пока не поддерживаются.

На TV используйте стрелки, OK и Назад. Выбранный элемент выделен рамкой. Слайдер меняется влево/вправо. В пиксельном редакторе OK включает рисование, стрелки двигают курсор, OK ставит пиксель, Назад завершает рисование. Большие файлы и точные рисунки удобнее загружать с телефона.

## 6. Свои команды, аудио и плагины

В «Сценариях» задайте точную триггер-фразу и действия. Аудиофайл можно загрузить и воспроизводить по своей фразе. Это не замена всего голоса Алисы.

В «Плагинах» выберите файл **`.yampkg`**. До установки проверьте совместимость, состав и показанные установочные действия. Команды плагина выполняются с root: используйте пакеты авторов, которым доверяете. Формат `.yap` другого менеджера не поддерживается. Управление установленной службой и журнал доступны здесь же.

## 7. Приватность

Раздел проверяет установленные приложения, объявленные разрешения и известные библиотеки аналитики в их коде. Наличие библиотеки не доказывает отправку данных; отсутствие известной сигнатуры не гарантирует отсутствие слежения. Это не сетевой перехватчик.

Дополнительные приложения можно отключить и восстановить. Данные и аккаунты при этом сохраняются. Основные службы Алисы, настройки, текущий поддерживаемый лаунчер, Play и сама панель защищены от отключения этой кнопкой. Облачная Алиса продолжает обращаться к Яндексу. Аппаратная кнопка отключения микрофонов остаётся доступна. Полностью исключить связь с Яндексом при сохранении облачной Алисы этот выпуск не обещает.

## Обновление и откат

APK управления проверяет подписанный общий канал GitHub через интернет, даже когда станция недоступна. Открывать GitHub из приложения не требуется. Android попросит завершить установку обновления. Изменения веб-интерфейса и функций агента требуют также обновления комплекта станции: повторите установку **нового** комплекта на своей совместимой станции. В комплекте TV-версия устанавливается вместе с агентом.

Обновление панели не является обновлением Android. Полная новая совместимая прошивка здесь не распространяется.

Откат файлов агента из сохранённой установщиком копии:

```text
python setup.py --serial АДРЕС:ПОРТ --rollback --reboot
```

## Если не работает

- **Станция не найдена:** проверьте одну Wi-Fi сеть, изоляцию гостевой сети, VPN и установку агента; попробуйте ручной адрес.
- **Код отклонён:** создайте новый на TV; старый одноразовый код может истечь. Не вводите пароль аккаунта.
- **Нет музыки/обложки:** откройте выбранный сервис на станции, проверьте аккаунт, начните воспроизведение. Некоторые сервисы не публикуют обложку или команды.
- **Визуализация реагирует на видео:** выберите источник «Выбранный музыкальный сервис» и нужный сервис в «Музыке».
- **LED выглядит иначе, чем картинка:** это 400 монохромных точек. Используйте крупный силуэт, предпросмотр и настройку полутонов; мелкий текст и детали неизбежно теряются.
- **После обновления интерфейс старый:** обновите агент комплектом и заново откройте панель. Одно обновление телефонного APK не заменяет агент.
- **Приложение не устанавливается:** проверьте Android 6+, свободное место и происхождение установленного APK. Сборка с другой подписью не обновляет официальный пакет поверх существующего.

Для сообщения об ошибке укажите модель, сборку Android, версию приложения, выбранный плеер и последовательность действий. Не публикуйте ключ подключения, пароли, токены и личные журналы.

«Загрузки» — официальный лаунчер, ссылки на телевизионные версии приложений,

Длинные списки и само меню прокручиваются при переходе к следующему пункту.
Для рисования и выбора фото используется приложение телефона; медиатека
остаётся общей и хранится на станции.

Поля настроек плагина доступны, если автор включил описание интерфейса.
Для существующих пакетов без него доступны службы и журнал. Формат для авторов:

Кнопка «Проверить и установить» проверяет хеш уже установленного ТВ-приложения.

может закрыться: откройте его вновь, чтобы прочитать итог фоновой установки.

## Новое в 2.4: сообщество, AirPlay и компьютер

**Телефон:** установите Station-Studio-2.8.2.apk. Для новой функциональности также обновите агент станции комплектом Max 0921. Обновление APK телефона отдельно не заменяет агент на станции.

**Компьютер Windows 10/11 x64:** скачайте Station-Studio-PC-2.8.0.exe из выпуска и запустите. Откроется отдельное окно через установленный Microsoft Edge; при его отсутствии используется браузер по умолчанию. Нажмите «Найти станцию в сети». Если поиск не сработал из-за VPN/гостевой сети, введите её локальный адрес. На станции откройте код подключения в настройках, затем введите код в приложении ПК. Ключ шифруется Windows DPAPI. Для последующих подключений телефон не нужен. Проверка обновления есть в меню подключения ПК; обновления сверяются с подписанным каналом и SHA-256. EXE пока без сертификата издателя Windows.

**AirPlay:** Возможности → Загрузки → AirPlay. После установки откройте приёмник на станции, затем «Настроить AirPlay» в его карточке. Устройства Apple должны быть в той же сети; гостевая изоляция мешает обнаружению. Можно выбрать имя, PIN, автозапуск, разрешение и частоту кадров. Изменения имени/PIN применяются после перезапуска приёмника через его экран настроек. DRM-видео не поддерживается. Передача с Apple-устройств проверяется отдельно: наличие приёмника не гарантирует совместимость каждого приложения.

**Сообщество:** отдельная вкладка внутри «Возможности». Встроенные функции находятся в «Обзоре», программы Android — в «Загрузках»/«Установлено». Плагин можно скачать из каталога или загрузить локальный .yampkg; загрузка не равна установке. Посмотрите состав, версию и права, затем подтвердите установку. Настройки и службы открываются в карточке установленного плагина. Удаление архива не удаляет установленную копию; удаление пакета останавливает его управляемые службы.

**Создание:** Сообщество → Мастерская → Создать с ИИ. Скопируйте всю инструкцию в свой ИИ; он уточнит идею, название и эмблему. Готовый SDK с примером и сборщиком — Station-Studio-Creator-SDK.zip в выпуске. Для проверки используйте локальную загрузку пакета. HTML-страница автора изолирована, имеет доступ только к своим параметрам и не получает ключ станции; на ТВ всегда используются стандартные элементы для пульта.

**Публикация:** https://station-studio-community.shaaaape.chatgpt.site. Скачивание без входа, публикация и управление своими выпусками — через ChatGPT. Один новый плагин в день UTC, обновления без суточного лимита. Удаление не освобождает суточный слот. Опубликованные пакеты общедоступны. Root-код автора не является песочницей; отзыв доверия блокирует последующий запуск управляемых служб, но не отменяет уже внесённые кодом изменения.

Каталог и файлы раздаются через GitHub Releases. Публикации, обновления и удаления синхронизируются обычно раз в 15 минут; расписание GitHub может задерживаться. Установка и отзыв прав на собственной станции применяются локально сразу.

## Оформление и 3D-плагины в AliceKit 2.6

В «Настройки → Эффекты приложения» выбираются полные эффекты, спокойный режим или отключение анимаций. Системное уменьшение движения учитывается автоматически. Музыкальный экран использует реальную обложку активного трека; при паузе движение прекращается. Если обложка недоступна, используется нейтральный фон.

Модель Станции Макс на главном экране показывает фактический буфер LED25×16 и24диода кольца с задержкой сети. Аппаратное чтение подтверждено для прошивки5000000921; для остальных прошивок оно не объявляется рабочим. Это не видеокамера, фото комнаты или датчик положения станции. Модель можно повернуть пальцем.

Авторские интерфейсы и3D-пространства: Возможности → Сообщество → карточка установленного плагина → Настройки и службы. Модель, текстуры и библиотеки входят в пакет. ВнешниеCDN не нужны. На ТВ сначала нажмите «Управлять сценой»: стрелки управляют сценой, OK выполняет действие, Назад возвращает управление панели. Основные параметры по-прежнему доступны стандартными полями.

### Светомузыка и группы дома (2.7)

Телевизор: Оформление → Кольцо → Синхронизировать с музыкой. Выберите источник, место показа и эффект; нажмите Включить светомузыку. Статус сообщает, идёт ли показ или станция ждёт музыку. Цвета обложки требуют обложку от выбранного плеера; при её отсутствии выберите свою гамму. Пауза и смена звукового буфера не требуют перезапуска приложения.

Лампы: Оформление → Умный свет. Поддерживаемые цветные лампы Дома с Алисой появляются после подключения аккаунта. Сначала включите выбранные лампы; панель не включает выключенные автоматически. До четырёх облачных ламп за запуск, интервал от четырёх секунд. Это плавное облачное световое сопровождение, не мгновенный эквалайзер; для быстрой реакции нужны локальные WLED или Yeelight LAN Control. Исходный доступный цвет сохраняется перед запуском и восстанавливается при остановке, если команда действительно меняла свет.

Группы, переданные Домом с Алисой, показываются общей карточкой. Дочерние устройства открываются внутри неё. Изображения и фоны провайдера используются, когда API возвращает поддерживаемые HTTPS-ссылки; фотографии есть не у всех устройств.

При подключении через точку доступа телефона она может блокировать поиск/связь между клиентами. В таком случае используйте домашний роутер либо укажите адрес станции вручную. Для ранее подключённой станции новый адрес проверяется по сохранённому сертификату.


## Мастер, дисплей и профиль (2.8)

В поиске можно выбрать обнаруженную обычную станцию и открыть пять шагов: сеть, ADB, root, установка, подключение. Для получения ADB мастер открывает AliceBridge и исходные сообщения сообщества. Сбрасывать уже работающую станцию не требуется. Автоматического root для любой модели нет. На компьютере доступен отдельный путь с оригинальным установщиком; сначала выполняйте проверку модели, затем следуйте инструкции архива.

В разделе «Дисплей» есть отдельные кнопки: «Убрать трек», «Штатный дисплей» и «Погасить». Первая убирает постоянное название и его сохранённый автозапуск. Вторая останавливает пользовательские эффекты матрицы и возвращает штатные анимации. Кольцо без визуализации на матрице сохраняется. «Погасить» оставляет возможность штатных уведомлений Алисы.

В настройках выберите тёмную или светлую Станцию Макс. Выбор хранится на станции, синхронизируется между клиентами и меняет фотографию, материал и верхнюю панель живой модели.

Профиль находится в настройках. Имя и цвет сохраняются отдельно для каждого подключённого устройства. Вход через @AliceKitBot необязателен: нажмите «Войти через Telegram», откройте бота и явно подтвердите вход, затем вернитесь кнопкой бота или вставьте его подтверждение в AliceKit. Первое подтверждение создаёт привязку автоматически. Ссылка и подтверждение действуют пять минут, используются один раз и связаны с запросом этого устройства. На TV можно сканировать QR телефоном и вставить подтверждение на том клиенте, где начат вход.

Это локальные профили подключённых устройств, не облачная синхронизация домов и не выдача доступа к станции по одному Telegram-аккаунту. Сопряжение станции отдельно защищено одноразовым кодом и сертификатом. Секреты бота и ключ подписи находятся только на сервере. В APK и агенте есть только публичный ключ проверки. На станции сохраняются Telegram ID, имя и username; телефон, пароль и сессия Telegram не запрашиваются. Отвязка удаляет Telegram-данные из профиля.

Профиль мобильной установки использует параметр оригинального Hybrid Root `IPV6=drop`: блокируется DNS-over-TLS по IPv6 для защиты DNS-правил; весь IPv6 не отключается. В старой конфигурации `none` на сети с IPv6 root может работать, но защита показывает `DEGRADED / ipv6-unprotected`. Это разные состояния: наличие UID 0 не доказывает полноту сетевой защиты.
